API Endpoints & Server Actions

REST + Server Actions
Method Endpoint Purpose
GET /api/tasks List tasks with filtering by status, priority, assignee
POST /api/tasks Create new task and emit activity log event
GET /api/tasks/[id] Fetch single task with relations (assignee, subtasks, comments)
PATCH /api/tasks/[id] Update task attributes, status transitions, priority
DELETE /api/tasks/[id] Delete task and cascade delete subtasks/comments
GET /api/team Fetch workspace members and pending invitation tokens
POST /api/team Invite new member and generate secure acceptance link
DELETE /api/team/[id] Revoke team membership and reassign active tasks
POST /api/comments Post comment on task thread and trigger notifications
